# Bike-Share-Demand-Analysis-in-R
Analyzing bike share usage patterns with R (loops, cumsum, aggregation, and weather-based insights)

# Overview
This project analyzes bikeshare usage patterns using R, with a focus on seasonal trends, cumulative counts, daily aggregation, and weather-related comparisons.

# Key Tasks
- Calculated the number of hours required to reach 50,000 cumulative bikers for each season
- Solved the same problem using both loops and vectorization
- Aggregated hourly winter data into daily total bikers
- Identified low-demand winter days
- Compared average temperature, humidity, and windspeed between lower-demand and higher-demand days
